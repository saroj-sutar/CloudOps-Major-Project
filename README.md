# CloudOps Enterprise Platform

CloudOps Enterprise Platform is a cloud infrastructure, automation, containerization and CI/CD project developed as part of the Major Project.

## Technologies Used

- AWS
- Terraform
- Docker
- Docker Compose
- Kubernetes
- AWS Lambda
- Amazon API Gateway
- Amazon S3
- IAM
- Amazon CloudWatch
- GitHub Actions

## Project Components

### Cloud Infrastructure
- AWS EC2 web server
- Security Group
- Amazon S3 storage
- S3 versioning
- S3 lifecycle management
- S3 server-side encryption

### Containerization
- Docker image
- Docker container
- Docker Compose
- Nginx web application

### Kubernetes
- Kubernetes deployment
- Kubernetes pod
- Kubernetes service
- NodePort / port forwarding

### Serverless
- AWS Lambda function
- Lambda Function URL
- API Gateway
- CloudWatch monitoring

### Infrastructure as Code
- Terraform configuration for AWS infrastructure

### CI/CD
- GitHub Actions
- Automated project validation
- Docker image build

## Application

The application displays:

**CloudOps Enterprise Platform**

The web application is deployed using AWS EC2, Docker and Kubernetes.
