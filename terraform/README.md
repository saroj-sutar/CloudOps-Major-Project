# CloudOps Enterprise Platform - Terraform

This Terraform configuration provisions and manages the AWS infrastructure for the CloudOps Enterprise Platform.

## Resources

- AWS EC2 Web Server
- AWS Security Group
- AWS S3 Bucket
- S3 Versioning
- S3 Lifecycle Configuration
- S3 Server-Side Encryption

## Region

AWS Region: ap-south-1

## Terraform

Terraform is used as Infrastructure as Code (IaC) to provision and manage the cloud resources.
